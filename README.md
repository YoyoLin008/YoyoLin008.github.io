# Yoyo Lin — Personal Website

This repository contains the source for [yoyolin008.github.io](https://yoyolin008.github.io/), my personal website.

I'm an Information Sciences + Data Science student at the University of Illinois Urbana-Champaign, with a minor in Computer Science. The site brings together my academic work, professional experience, and personal interests.

## Explore the site

[Experience](https://yoyolin008.github.io/#experience) covers my research roles and internships in a chronological timeline, alongside education, honors, and a link to my resume.

[Publications](https://yoyolin008.github.io/#publications) presents submitted manuscripts and research in progress, with figures and links to available papers, code, and reproducibility materials.

[Hobbies](https://yoyolin008.github.io/#hobbies) includes a bird photography portfolio and a Tech page where I share older phones, mobile interfaces, and aircraft I've photographed.

## About this repository

The website is built with HTML, CSS, and JavaScript and hosted on GitHub Pages. This repository holds the site content, styles, photographs, and documents. Research code is linked from the individual publication entries.
